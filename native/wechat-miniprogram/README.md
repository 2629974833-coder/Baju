# 微信视频分享接入原型

这个原型实际调用 `wx.shareVideoMessage`，目标是打开微信提供的视频转发流程，由用户选择好友并确认。不会自动选联系人或发送。不是网页 `navigator.share` 的改名。

## 当前范围

先选取一个本地视频，再用同一个“分享给微信好友”按钮转发。优先使用相册选择；环境未提供相册选择时尝试聊天文件选择。逐项检测微信当前环境的实际能力，不把电脑微信支持当作已验证事实。

这里尚未把 Baju 网页的视频自动传入小程序。需要先完成实际账号、实际设备的微信转发验收，再设计受限的视频交接，不传递网站管理员密码、账号登录凭据或永久公开的私人视频地址。

## 如何打开

1. 用微信开发者工具导入当前目录。
2. 把 `project.config.json` 中的 `appid` 改成自己的真实小程序编号。编号不是密码；不得把账号密码或密钥写入代码。
3. 当前默认值 `touristappid` 只用于查看工程，不代表已经注册或具备真实分享权限。
4. 预览到真实手机，在微信中先选择自己有权分享的本地视频，再点同一按钮，检查是否出现好友选择，以及好友收到的是否为可播放的视频。
5. 若需要测试收件效果，请自行选择测试对象并发送；自动测试只使用替身，不发送给任何人。

## 验证情况

控制逻辑已由自动测试检查：选视频不自动发送、准备好才调用视频转发、不用文件转发伪装为视频、环境不支持时明确提示、取消和失败可重试、页面退出后忽略旧结果。

尚未用真实小程序编号或真实手机执行微信转发。电脑、苹果和安卓的真实行为均需实机验收。这个原型不代表网页单按钮到微信的完整链路已完成。

## 依据

- 微信官方接口定义：<https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts>
- 官方视频转发文档：<https://developers.weixin.qq.com/miniprogram/dev/api/share/wx.shareVideoMessage.html>

官方定义说明 `videoPath` 必须是本地或临时视频路径，而不是任意网页地址；接口用于“转发视频到聊天”。
