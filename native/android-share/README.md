# 安卓直接交给微信：离线测试应用

这个应用不需要微信小程序账号。它使用安卓系统的文件交接功能，把用户选取的视频交给包名为 `com.tencent.mm` 的微信，再由用户在微信内选择好友并确认。

**当前只验证接入路线，尚未连接 Baju 网页素材库，也未在真实手机上测试。**安装包能编译、签名校验通过，不代表微信已接受转发，更不代表好友已收到可直接播放的视频。

## 使用

1. 在安卓 8.0 或更新版本的手机上安装测试包。
2. 打开“拾帧转微信测试”，点击唯一的分享按钮，选择一段有权分享的 MP4 视频。
3. 应用只复制这段视频到自己的临时存储区，然后尝试打开微信的视频分享界面。
4. 是否选择好友、是否发送，都由用户自己决定。返回后不会把返回状态当作发送成功。
5. 记录是否出现好友选择、对方收到的是视频还是文件、能否直接播放和保存。失败也请保留具体表现，用于决定是否继续采用此路线。

如果从网页的系统分享菜单中选择本应用，应用也可接受该视频再交给微信。当前仍有这次系统选择；尚未实现普通网页中一键跳进配套应用。

此应用不申请联网、联系人、短信、相册整体访问权限，只读取你通过系统选择器选取或明确分享进来的文件。仅接收本地内容地址，限制单次最多 128 MiB（约 134 MB），不改变水印，不覆盖原件。微信只获得该视频临时地址的只读权限。临时视频位于应用自身缓存中，测试完可通过系统清理本应用缓存移除。

## 构建

使用谷歌官方 Android 构建工具 35.0.0、安卓 35 的 `android.jar`，以及 Adoptium 官方发布的 Temurin OpenJDK 17.0.21+9。构建工具和依赖下载后与官方校验值核对。

当前测试包已完成实际编译，安装包的第二代和第三代完整性校验通过；权限清单未声明联网或联系人访问。尚未安装到真实安卓手机，未声称微信已接收视频或消息已发送。

```sh
python build.py --jdk /path/to/jdk --build-tools /path/to/build-tools --android-jar /path/to/android.jar --output /path/to/framekeep-wechat-test.apk
```

这是测试签名，不用于商店发布。生成的测试私钥保留在被忽略的 `.build/` 内，不提交到代码仓库。应用没有接入任何微信账号、密码或密钥。
