# 拾帧 Framekeep

中文个人媒体工作空间：通过用户自己的浏览器会话发现可访问的图片、视频，选择素材下载到本机，并保留文件大小、尺寸、时长和 SHA256。前端为原生 JavaScript/CSS，真实服务使用 FastAPI、Playwright、SQLite、yt-dlp 和 FFmpeg，不需要前端构建、Redis 或 GPU。

首页「拾取链接」支持**整站、整部剧、单集或短视频**三种范围。结果按剧和集列出图片、视频，可单项或批量下载和导出。操作示例、短视频水印处理和范围限制见[拾取链接](docs/INTAKE.md)。

抖音、YouTube、TikTok、Instagram 的单作品下载、源水印说明及实际服务器验收见[社交视频下载](docs/SOCIAL_DOWNLOADS.md)。

支持两种运行方式：**本地个人工作空间**提供来源授权、剧集管理、下载和 CPU 处理；**公开下载工具**免注册，每位访客的任务与文件独立。服务器部署见下方入口，运行维护和媒体处理见 [运行维护](docs/OPERATIONS.md) 与 [CPU 处理](docs/PROCESSING.md)。

**当前默认入口是真实本地服务。** Lustflix 已验证保存会话恢复、公开预览和免费首集下载。春楼已支持从单集链接识别指定作品、展开已发布的主线目录和收集站点列出的剧图。日常浏览器已登录春楼时，可从「来源 → 春楼 CHUNLOU → 站点授权 → 使用已登录的浏览器」关联账号。Candy AI 和 Moolight 目前提供配置入口。各站点、账号与播放格式的验收范围见[首批站点验收](docs/SITE_ACCEPTANCE.md)。

通过「[自动化](http://127.0.0.1:4173/#automation)」可以持续检查常用页面。新规则默认只发现素材；勾选自动下载后，符合条件的新增素材进入下载队列。设置与验收方法见[自动化使用说明](docs/AUTOMATION.md)。

## 本地运行

需要 Python 3.12+、[uv](https://docs.astral.sh/uv/getting-started/installation/) 和 FFmpeg（包含 `ffprobe`）。macOS 可先执行 `brew install ffmpeg`；Debian/Ubuntu 可使用系统包管理器安装 `ffmpeg`。在本目录执行：

```sh
uv sync --frozen
uv run playwright install chromium
uv run python -m backend
```

Linux 首次安装 Chromium 时使用 `uv run playwright install --with-deps chromium`，系统依赖安装可能需要管理员权限。浏览器安装方式见 [Playwright 官方说明](https://playwright.dev/python/docs/browsers)。`npm run dev` 是相同真实后端的快捷入口。

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173) 或 [http://localhost:4173](http://localhost:4173)。默认只监听本机，无口令时不需要管理员登录；存活检查 `/api/health` 返回 `{"status":"ok","mode":"real"}`，就绪检查 [http://127.0.0.1:4173/api/ready](http://127.0.0.1:4173/api/ready) 检查工作循环、依赖、数据库和磁盘，未就绪时返回 503。端口占用时可换用 4174；每个工作区只允许一个后端进程，第二个实例必须同时使用不同的 `FRAMEKEEP_DATA_DIR`。启动会读取 `.env`，已设置的进程环境变量优先。

1. 公开作品无需登录：在总览粘贴链接，选择「单集或短视频」，点「直接下载」，完成后保存到本机。只有源站确实要求账号时，本地模式才需要在「站点与授权」打开站点窗口并保存会话；登录和验证码等由用户自己完成。
2. 从页面或栏目链接发起有限范围扫描。遇到登录或验证页面时，先回到站点窗口处理，再重新扫描。在「素材发现」勾选不需要的结果，或先筛选再全选，点击「删除所选」即可从发现列表移除。相同记录再次扫描时继续隐藏；已下载文件仍可在「文件与成品」查看。
3. 选择已发现素材加入下载队列；视频可查看源站选项并指定最高画质和音轨语言，批量任务也可统一设置。下载完成后在「文件与成品」预览或保存原件。
4. 在「处理工作台」批选原件，配置文字水印或固定去除区域，生成独立成品版本。完成后可对比原件、切换版本、下载文件或分类 ZIP；配置预览与实际处理效果分别展示。
5. 在「设置」检查运行状态和剩余空间；暂停活动任务后可创建并校验完整备份。恢复到新空目录使用离线 CLI，步骤见 [运行维护说明](docs/OPERATIONS.md)。

按整部剧管理时使用「[剧集库](http://127.0.0.1:4173/#series)」：一个详情页或播放页链接 → 自动展开可识别的选集或结构化目录并逐集扫描 → 统一下载。可继续扫描剩余集数、批量重新检查权限、跨次归并目录、按剧名和集号导出。识别范围、接口和本地验收见 [剧集库说明](docs/SERIES_LIBRARY.md)。

关闭网页不会停止运行中的后端任务。停止后端会中断扫描；正在下载或处理的任务保留为暂停，排队任务重启后继续排队。HTTP 在可靠验证器和 Range 可用时续传，HLS 校验清单与缓存后复用片段；CPU 处理继续时从原件重新处理，不提供编码帧断点续算。本地数据默认存放在 `.framekeep/`，可用 `FRAMEKEEP_DATA_DIR` 更改。

## 当前功能与边界

| 能力 | 当前状态 |
| --- | --- |
| 站点会话 | 用户在站点窗口操作；保存的浏览器状态加密存放在本机 |
| 素材发现 | 有界页面遍历，识别页面图片、视频及已观测到的媒体请求；不是全站完整性保证 |
| 剧集库 | 单链接目录发现、逐集解析、历次归并、选集/整剧批量下载及 ZIP 导出；未知总数与需权限条目分别显示 |
| 直接下载 | HTTP/HTTPS 图片和视频；拒绝登录页、错误页、不完整传输和超限文件 |
| HLS 点播 | 支持普通清单、相对/签名链接、独立音轨及普通授权 AES-128；生成真实 MP4 |
| 下载校验 | Pillow 图片校验、FFprobe 媒体轨道与时长校验、SHA256、原子保存 |
| 任务控制 | 持久化续传、瞬态错误有界重试、同素材单写入、并发上限 4、暂停/继续/取消及重启恢复 |
| 下载选项 | HLS / 静态 DASH 选择源站已有画质与语言；任务保存偏好、展示实际结果，失败后可调整重试；直接文件保持原件 |
| 内容识别 | 预览、正片候选、独立音轨、待确认；带依据和置信度，支持人工修正及恢复自动识别 |
| CPU 水印处理 | Pillow 图片加字、固定区域边缘插值；FFmpeg 视频加字、固定矩形 delogo；真实单任务处理队列与暂停/重试/取消 |
| 文件与成品 | 原件不覆盖；版本元数据、参数和哈希留存，原件/版本预览、Range、分类筛选和分类 ZIP |
| 运行维护 | 就绪诊断、工作循环心跳、磁盘保留阈值、工作区进程锁、在线静止备份、显式校验与离线新目录恢复 |
| 定时与自动化规则 | [自动化规则](docs/AUTOMATION.md)支持定时只读检查指定页面，按类型记录新增素材，可选加入真实下载队列，遇到登录验证可处理后恢复 |

已接入 yt-dlp 通用网页提取、三种平台的单作品解析、受限静态 DASH、原页面链接刷新和剧集目录；支持范围与验收见 [开源接入记录](docs/OPEN_SOURCE_DOWNLOADS.md)。仍不支持直播、任意站点专用 extractor、HLS 字节范围清单、变量、会话密钥和低延迟片段等扩展；不绕过 DRM。站点可能因验证码、短效链接、专用播放器或权限要求而无法扫描或下载。普通 AES-128 与 DRM 并不等同，前者只在用户会话能获取合法密钥时处理。

默认运行方式面向**个人单管理员**；公开模式另行启用独立访客工作区、容量限制和功能限制。浏览器与下载器采用基础 URL 策略和固定 IP 出口代理；服务器仍应使用受控网络出口。`FRAMEKEEP_TRUST_FAKE_DNS` 默认关闭，只有明确使用并信任自己的 Fake-IP/TUN 代理时才开启。服务器部署、管理员口令、存储和备份见 [部署说明](docs/DEPLOYMENT.md)。

春楼半透明飘字可在工作室一键识别和修复，其他水印可手动画框或记录移动关键帧。复杂背景可能留痕。工作室和资料库使用同一份剧集目录，支持按剧名找到本地视频。成品按来源、媒体类型和已有标签归类，不包含语义 AI 分类。中文处理需要覆盖文字的本地字体，容器配置安装 Noto CJK；无超分阶段。

## 服务器部署

需要 Docker Compose，按用途选择配置：

- **个人使用**：按 [个人服务器部署](docs/DEPLOYMENT.md) 配置管理员口令和持久化存储。
- **公开下载工具**：按 [独立访客工作区部署](docs/DEPLOYMENT.md#公开下载工具免注册独立访客工作区) 使用 `deploy/.env.public.example`、`compose.production.yaml` 与 `compose.public.yaml`。支持域名 HTTPS 和 IP 入口，访客无需注册。

公开模式使用服务器网络和临时磁盘；用户点击保存或导出 ZIP 后，文件才传到自己的电脑。工作区按浏览器隔离并自动过期，不共享站长账号；公开入口关闭维护、自动化、CPU 后处理与自动解锁。R2 尚未接入。

仓库仅包含源码、依赖锁、测试和配置示例，不包含媒体文件、站点登录会话、数据库、实际环境配置或私人部署记录。首次运行会创建自己的工作区。

## 保留的交互原型

原型仍可使用 Node.js 22+ 独立启动；如果真实后端占用了 4173，可换用 4174：

```sh
PORT=4174 npm run dev:demo
```

打开 [http://localhost:4174](http://localhost:4174)。该入口仅提供静态界面：扫描、登录、解锁、下载、水印处理与版本记录均为模拟，不会生成真实媒体文件。示例图片来自 Unsplash，不是从显示的来源站点抓取的内容。以下表格保留原型的交互范围，真实服务能力以上表为准。

| 页面 | 当前可操作的功能 |
| --- | --- |
| 素材发现 | 新建模拟扫描、搜索、来源与分类筛选、网格/列表切换、收藏、标签、预览和批量选择 |
| 下载队列 | 模拟进度、状态筛选、暂停、继续、重试和移除任务，下载完成后进入处理 |
| 处理工作台 | 选择已下载素材，配置去水印/加水印模板、文字、位置和透明度，启动模拟处理 |
| 成品库 | 查看处理结果、原件及版本记录，分类筛选，导出素材清单 |
| 站点与授权 | 添加演示站点、连接或退出模拟账号、查看访问状态、确认模拟解锁 |
| 自动化规则 | 创建、编辑、启停和删除规则；仅保存配置，不执行后台定时任务 |
| 设置 | 下载并发、下载完成后自动模拟处理、导出清单和恢复初始演示 |

原型的素材、任务、站点和规则保存在当前浏览器的 `localStorage`，与真实服务的 SQLite 和媒体存储分开。刷新页面可恢复原型状态；更换浏览器或清除浏览器数据不会保留这些记录。未完成的模拟任务只在页面打开时推进。原型导出的是 JSON 清单，不是视频或图片文件。

原型水印工作台展示的是配置示意，未执行真实修复。真实模式已使用独立后端处理队列和实际文件版本，与原型模拟数据分开；范围见 [CPU 处理说明](docs/PROCESSING.md)。用户在真实站点窗口输入的登录信息会传给目标站点，保存会话时本机会加密保存浏览器状态。

## 验证入口

原型阶段已核对的桌面浏览器流程：

- 待解锁素材 → 确认模拟解锁 → 加入下载队列。
- 下载暂停 → 继续；Vimeo 授权恢复 → 失败任务重试。
- 已下载素材 → 配置水印 → 模拟处理 → 成品库与版本记录。
- 新建模拟扫描 → 新素材出现；创建自动化规则 → 规则列表更新。

已检查 1440px 桌面与 390px 手机布局、导航和关键交互；详细记录见 `docs/QA.md`。可以从「设置 → 重置演示」恢复初始状态后重复上述流程。

## 文件入口

- `backend/app.py`、`backend/__main__.py`：API、静态入口和单进程真实服务。
- `backend/browser.py`、`backend/scanner.py`：站点会话与有界媒体发现。
- `backend/downloader.py`、`backend/tasks.py`：真实下载、媒体验证与任务控制。
- `backend/processing.py`、`backend/processing_tasks.py`、`backend/processing_api.py`：CPU 处理、持久化队列与版本归档。
- `backend/operations.py`、`backend/operations_api.py`、`backend/backup.py`：运行诊断、维护状态、完整备份和离线恢复。
- `backend/store.py`、`backend/thumbnails.py`：SQLite 持久化与缩略图。
- `dist/app.js`：导航、页面事件与真实/原型模式入口。
- `dist/model.js`：素材、站点、权限和任务状态转换。
- `dist/sites-view.js`：站点授权与解锁界面。
- `dist/workflow-view.js`：下载、处理、规则和设置界面。
- `dist/assets/`：本地示例图片与图标。
- `tests_backend/`、`tests/`：真实后端与前端状态逻辑测试。
- `Dockerfile`、`compose.yaml`、`.env.example`：[个人服务器部署](docs/DEPLOYMENT.md)。
- `docs/PLAN.md`：原型范围与设计方向。
- `docs/NEXT_STEPS.md`：真实服务接入顺序和验收方式。

静态发布只能提供交互原型；真实会话、扫描与下载需要运行本仓库后端。

下载模块逐项验收、故障恢复和复跑入口见 [下载验收](docs/DOWNLOAD_ACCEPTANCE.md)。

画质和音轨选择的支持范围、API 与本轮真实验收见 [下载选项](docs/DOWNLOAD_SELECTION.md)。

整剧目录、选集下载与编号导出的第一阶段历史验收见 [STAGE1_SERIES.md](docs/STAGE1_SERIES.md)，其中现场结论只对应当时范围。最新本地能力与验收记录见 [QA](docs/QA.md)；受控样例不代表任意真实站点整剧覆盖。
