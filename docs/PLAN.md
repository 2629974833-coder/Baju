# 拾帧 Framekeep 交互原型

视觉方向：温暖白底、森林绿强调、细线分区，以大幅实景缩略图组织密集但安静的素材工作区。

内容结构：固定侧栏及顶栏；素材发现为首屏；下载队列、处理工作台、成品库作为主流程；站点授权、自动化规则和设置作为支持流程。

交互方向：快速抽屉/弹窗过渡；选中素材与底部批量操作栏联动；扫描和任务进度可见，尊重 reduced-motion。

范围：浏览器端演示，所有数据和模拟任务存于当前浏览器。真实登录、支付、抓取、下载、图像与视频处理均尚未接入。原型不收集密码、Cookie、支付资料。无超分辨率。

主要流程：
1. 站点登录演示、权限状态、待解锁条目及逐项模拟解锁，保留操作记录。
2. 新建扫描，限制页面数与深度，浏览和筛选候选素材。
3. 勾选加入队列；锁定素材必须先模拟解锁；去重、暂停、继续和重试。
4. 已完成下载选择去水印/加水印模板，预览配置，模拟处理并保留原件。
5. 成品库按类型、站点、标签筛选；查看版本，导出演示清单。
6. 自动化规则可创建/开关，明确仅为原型配置、不会后台执行。

验收：状态逻辑测试；每个导航可访问；主流程浏览器交互；桌面和手机截图；静态文件和本地入口检查；原型演示限制清晰。
