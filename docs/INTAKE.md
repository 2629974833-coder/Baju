# 拾取链接

在[总览页](http://127.0.0.1:4173/#home)粘贴一个链接，选择想读取的范围。单集或短视频点「直接下载」，解析成功后自动进入下载队列，完成后可保存到本机；公开作品不需要先登录。整站或整部剧点「开始拾取」，结果直接进入「剧集」。如果是播放页，同一个地址可以用来找整部剧，也可以只读当前集。每次拾取都可从总览的「扫描历史」重开。原「发现」入口已合并到总览，旧链接 `#discover` 会跳转总览。

| 范围 | 输入 | 可用结果 |
| --- | --- | --- |
| 整站 | 站点主页或剧集索引页 | 从有依据的同源剧卡、索引分页、结构化目录或已适配的公开目录列剧，直接归入剧集页。按来源分组，支持分类、剧名筛选和分页；点「下载本剧」后扫描检查可访问的单集，再保存视频与海报。 |
| 整部剧 | 剧详情页或任一集播放页 | 识别目录并读取可访问的单集。若播放页给出明确的剧目录链接，会沿链接继续。自定义剧名会用于本次结果与导出。 |
| 单集或短视频 | 某集播放页、抖音、YouTube、TikTok 或 Instagram 的作品链接 | 只取该集或该作品。受支持的站内分享短链会先解析到具体作品。视频作品可有多个图像或视频附件。 |

**下载**将选中的素材加入拾帧队列，成功保存后可以预览或导出。**导出原件**将一个已保存文件交给浏览器。**导出本集、导出本剧、导出所选**按本次选择生成 ZIP，解压后从剧名目录进入，再按集号或剧内素材找到视频、图片。导出单部剧时，清单放在剧名目录内；导出多部剧时，各剧目录并列，根目录的清单列出各文件路径及可用的 SHA256。共用剧照在同一工作区保存一次，导出某集时放入该集自己的文件夹。直接视频链接能关联到以前保存的原件时，面板也可提供该原件。

## 读取范围

默认最多读取 100 个页面，单集模式只读目标作品。总览的整站拾取优先列剧并读取各剧目录，不逐集打开播放器。还没读到目录的剧卡会显示「选集目录待读取」，也可直接点「下载本剧」继续读取。程序支持每次最多 1000 页、500 部剧、5000 条单集目录记录和 1000 项素材；具体页面还受源站暴露的目录、时间与权限限制。还有待查索引或剧目录时，剧集页会显示「继续拾取」。下一轮沿已保存的目录和进度向后读，保留前轮取得的素材与归属。读取连续检查点仍受总规模限制。无法从来源确定总数时会保留未知状态。

总览的「其他待下载素材」保留历史扫描中尚未归入剧集的素材，支持搜索、分页、批量下载和移除记录。移除记录不删除已保存原件。剧集卡的海报会沿现有下载队列保存；整剧 ZIP 内为 `剧名/视频文件`、`剧名/海报.ext` 和 `剧名/manifest.json`，没有站点名父文件夹。海报仍在队列时等待保存后导出；源站没有海报或下载失败时，可导出已有文件，清单记录缺失情况。

首次接入的 Lustflix 采用发布方的公开目录及实际作品编号。通用站点依赖可辨认的剧卡、剧集列表、目录链接或结构化数据。需要登录或验证时，从「来源」处理后再读取。拾取流程使用只读访问。

## Lata Casa 目录与 Google 登录

输入 `https://lata.casa/series` 并选择「整站」，会读取站点发布的剧目索引，再列出各剧实际的选集目录与封面。输入 `/originals/…` 或 `/watch/…` 链接可选择「整部剧」；播放页选择「单集或短视频」只读取当前集。集数以页面目录和播放器数据相互核对，不按链接编号猜测。锁定集保留在目录里，登录后可用「扫描并检查」重新核对。

Lata 的 Google 登录使用独立的普通 Chrome 或 Edge 窗口。进入「来源 → lata.casa → 站点授权」，点击「使用本机浏览器授权」，在窗口内完成 Google 登录并返回 Lata，然后点击「保存本机浏览器会话」。保存时会向 Lata 确认本站已经登录，只有确认后才安装新会话；Google 域的会话不会导入拾帧。Linux 桌面需先从专用窗口菜单退出浏览器再保存。此入口需要拾帧运行在有图形桌面的本机。

已开放的单集从站点当前播放器读取 HLS 地址，沿现有下载队列保存为 MP4。锁定状态表示当前站点会话尚不能播放此集，扫描不会购买或开通会员。登录成功不等于取得全部剧集的播放权限。

## 春楼单集与站点授权

春楼的 `/feed?ep=…` 链接通过 `ep` 参数指定一集。粘贴后默认选择「单集或短视频」。要列出同剧已发布的主线集数，可在提交前切换到「整部剧」。例如，下方链接对应《想要和你一起》第 1 集。读取时，拾帧会核对集编号和所属剧。[春楼样本链接](https://chunlou.tv/feed?ep=ab7c97c5-5ebe-4e21-ae85-3a44cbf2a8d8)

如果日常浏览器已经登录春楼，可从「来源 → 春楼 CHUNLOU → 站点授权 → 使用已登录的浏览器」关联这个账号。请在运行拾帧的电脑上，用已经登录的那个浏览器打开交接页。[打开春楼账号交接页](http://127.0.0.1:4173/chunlou-connect.html?site=chunlou)

1. 将「关联春楼账号」拖入浏览器书签栏，或点「下载书签文件」后用浏览器的导入书签功能安装。下载的 HTML 仅含一个指向本机拾帧的脚本书签。
2. 在一个已登录的春楼标签页中，点浏览器书签栏里的「关联春楼账号」。这会打开本机拾帧的确认页。
3. 在弹出的确认页点「确认保存」。拾帧向春楼的账号服务核对当前登录身份后，加密保存会话。之后可以回到面板拾取链接。扫描前会在访问令牌临期时向春楼续期。如果站点要求重新关联，请在已登录的浏览器刷新春楼并再次确认保存。

如果春楼页已经显示你的头像，确认页却提示「旧版书签只检查了一个登录位置」，请点「更新已有书签」，将新版地址保存到原书签。切回刚才显示头像的春楼标签页，点更新后的书签，再到新打开的拾帧页确认。

内容页要求确认年龄时，由你在站点窗口完成。若希望单独登录一个账号，也可使用专用浏览器窗口。

1. 在运行拾帧的电脑上进入「来源 → 春楼 CHUNLOU → 站点授权」，点击「使用本机浏览器授权」。需要 macOS 或 Linux 图形桌面，以及已安装的 Chrome 或 Edge。[打开本地来源面板](http://127.0.0.1:4173/#sites)
2. 在弹出的专用窗口完成春楼要求的年龄确认、Cloudflare 验证和账号登录。登录窗口使用系统网络设置，使用独立的浏览器资料目录。等页面显示你的账号。
3. macOS 上直接回到拾帧点击「保存本机浏览器会话」。Linux 上先从专用窗口的浏览器菜单退出，然后点击保存。拾帧在窗口退出后离线读取春楼会话。看到保存成功提示后，重新拾取目标链接。

如果验证仍然失败，可在日常浏览器用相同网络打开春楼登录页，对比是否出现同一错误。Cloudflare 组件如显示数字错误码，可据此判断是组件加载问题，还是需要站点方处理。[Cloudflare 验证排错](https://developers.cloudflare.com/cloudflare-challenges/troubleshooting/challenge-solve-issues/)

通过页面访问检查后，面板可列出站点明确归属于此剧的封面等图片，选中并下载后即可导出。视频还要核对播放器清单。对于春楼播放器的 AES-128 视频，免费集或已确认购买的单集有全长清单时会显示「可下载」。选中下载后，可在资料库播放 MP4 或从剧集库导出原件。

## 短视频水印

四个平台的下载范围、完整音视频检查和实际验收方法见[单条社交视频下载](SOCIAL_DOWNLOADS.md)。

单作品入口使用 yt-dlp 的平台解析器及拾帧的受控网络请求。源站明确标注无水印时，优先选择该版本；只有播放源或水印状态未知时，结果会标注依据。作品能列出媒体后，还要由下载队列实际验证 CDN 是否允许传输。

对于已经保存且画面内有固定水印的原件，可点「选区去水印」，在工作台框选区域并生成独立版本，再导出去水印成品。此方式使用 CPU，适用于固定区域。平台验证、受限媒体和移动水印会影响可取得的结果。

可复跑的本机验收命令为 `uv run python scripts/intake_acceptance.py`。脚本启动临时站点和工作区，核对目录归属、下载去重、单集和整站 ZIP、原件哈希以及视频音轨完整解码。
