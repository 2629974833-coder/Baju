# 视频操作与站点拖动：预览版本

此分支供检查效果，尚未更新任何在线网站。

## 当前改动

- 站点授权窗口支持鼠标或手指拖动。松开后，把用户亲自绘制的有界轨迹交给远端浏览器执行；取消不发送轨迹，异常时释放鼠标。不是自动识别或解答验证码。
- 原件及处理版本增加 HEAD（只检查文件而不下载内容的请求）。保存前检查文件状态、内容类型和大小，再交给浏览器下载，避免把错误页保存成文件。
- 已下载视频右下角新增「⋯」菜单：分享给微信好友、保存到手机相册、无水印选项。完整资料库、公开模式预览与独立演示页共用菜单。
- 分享的是视频文件，不是需要管理员密码或临时工作区凭据的私人网址。先准备文件，再点击按钮打开手机系统分享窗口，确保由用户选择接收方。
- 可以选择已有的源站无水印原件或已完成的去水印版本；来源没有提供无水印文件时明确标记“暂未获取”。处理已有水印会打开工作室并选择当前素材及“去水印”方式，不会自动提交处理。
- 为这台 Windows（微软电脑系统）上的本地预览补充工作区文件锁，并兼容浏览器会话文件的写入。原有其他系统的锁及权限设置保留。

## 预览

准备一份自己有权使用的示例视频，然后在项目根目录运行：

```sh
python -m scripts.preview_sharing --sample /absolute/path/sample.mp4
```

打开 `http://127.0.0.1:4177/sharing-preview.html`。只监听本机地址，不对外发布。

演示数据单独放在 `.preview-data/`，不会写入默认个人工作区。启动器会重建此演示区里的素材、站点和任务记录，请勿把真实个人数据放进该目录。

「打开拖动测试」使用本机的普通滑块，不是真实验证码；不会复用任何账号。演示页链接到完整资料库及工作室，可继续检查已有处理界面。

## 已验证与仍需验证

- 243 项页面逻辑测试通过，包括新增的手动拖动、取消及下载错误处理。
- 本地接口、原件请求、处理版本、文件锁及会话并发的相关测试通过。
- 实际浏览器检查了桌面、390 像素宽的手机布局、播放、文件下载后逐字节比对、错误提示、远端测试滑块、选择去水印方式，以及分享所需的第二次点击。
- 分享窗口调用使用替身验证，没有向真实微信好友发送任何内容。未在真实苹果手机、安卓手机或微信内完成端到端验收。
- 扩大到公开服务测试时，54 项通过，4 项未通过；失败集中于 Windows 的权限位检查、打开文件后删除目录的行为。另有 2 项未纳入本机通过组：原项目备份代码依赖另一类系统的文件打开选项；本机无创建符号链接的权限。此分支不宣称完整的 Windows 公开服务或备份兼容性。

## 使用边界

直接分享视频文件要求浏览器支持系统文件分享，而且正式网站需要使用 HTTPS（加密的网址连接）。能否出现微信或“存储视频”，由设备系统、浏览器及微信决定，网页不能保证一步完成。无法使用时提供下载文件再发送/保存的操作说明。

分享准备最多读取 128 MiB（约 134 MB）的文件，并检查实际读取量；超过此范围使用浏览器直接下载，避免大量占用手机内存。取消对话框或切换版本会中止准备。

来源标记无水印和实际画面无水印不能完全等同。原始视频水印状态未知时会显示说明；去水印版本也需播放检查，复杂背景可能留痕。原件不覆盖。

**对方服务器上“所有视频都无法保存”的根因尚未确定。**本次验证证明本地文件存在时可正常保存，缺失时有明确提示；不能据此断言远端服务器的文件丢失、权限或部署问题已经修复。之后上线前还需由服务器所有者授权并检查实际文件及运行记录。
