# 自动化规则

在本地面板打开「自动化」，新建规则，选择已添加的来源，填写该站点要持续检查的页面。网址需与来源使用相同的协议、域名和端口。按需要选择图片、视频和检查间隔（15 分钟至 7 天，默认每天一次）。每次检查一个页面，适合定期收集栏目页上直接出现的新素材。需要从选集目录逐集解析时，使用「剧集库」。

## 首次使用

1. 默认只扫描。保存后可点「立即执行」，也可等待第一次到期检查。服务在后台执行，关闭面板标签页后仍按计划运行。
2. 在规则上查看本次新增和加入下载队列的数量。在「素材发现」检查结果，确认选对了页面和素材类型。
3. 如需自动保存，编辑规则并勾选自动下载。符合条件的新图片进入普通下载队列。对于视频，只把能在页面中明确选出的单集主媒体加入队列。保存结果和错误可在队列中查看。此前已入库的素材可从「素材发现」手动选择下载。
4. 检测到登录页、人机验证或明确的访问拒绝时，规则会暂停。在「来源」打开相应站点窗口，完成验证并保存会话，再回到规则重新开启。可用「立即执行」验证恢复结果。

## 调度与维护

- 最多保存 100 条规则。每条启用的规则按自己的间隔调度，多个任务复用现有的扫描槽和下载队列。已经入库的同一素材再次出现会复用原记录。
- 规则扫描在隔离的只读浏览器中执行。部分站点的正常读取也依赖 POST 或实时通道，在这些页面上可发现的内容受限。
- 每条规则保留最近 30 次普通页面检查记录。带有剧集目录证据的扫描另行保留，方便回看选集。
- 暂停或删除规则会停止以后的检查。此前已创建的下载任务在「队列」中单独管理。正在执行的规则可等本轮结束再编辑或删除。
- 运行中的服务负责计时，规则、期限和扫描结果保存在 SQLite。备份期间调度让出工作区，恢复备份后启用的到期规则会继续运行。
- 「系统 → 运行维护」提供自动化调度器心跳。如面板显示服务未就绪，请先检查磁盘保留空间、进程和工作区状态。

## 本地验收

从项目根目录运行以下命令。端到端脚本使用临时工作区、自建站点和 Chromium。它将临时数据库中的下次检查时间提前，验证服务重启时会自动执行已到期的规则。图片按源文件核对 SHA256，视频同时提供单集与预告，核对实际入队项、原件哈希和全轨解码。

```sh
uv run pytest tests_backend/test_automation_api.py tests_backend/test_automation_engine.py -q
uv run python scripts/automation_acceptance.py
```
