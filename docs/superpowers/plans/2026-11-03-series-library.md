# 剧集库与整剧扫描实施计划

> For agentic workers: use subagent-driven-development with bounded file ownership, TDD and verification-before-completion.

**目标：** 从一个目录或播放页链接建立剧集目录，自动逐集解析，按剧汇总并批量下载。

**架构：** 沿用 SQLite 中的扫描和素材记录，派生稳定剧集库；沿用下载队列、格式选项和 ZIP 导出。通用目录发现只采用页面明确展示的同源链接，不猜测集数或 URL。目录未知、权限不足、重复编号和候选冲突均明确显示。

**技术：** FastAPI、现有 Playwright 扫描器、现有下载器、原生 JavaScript。

用户已取消此前实际内容下载。本轮只使用本地非成人合成样例，不访问目标站点或解锁内容；更新主服务前仅在本地保存、备份既有会话。
